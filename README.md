# 📘 PolicyPortalWebApp1

**PolicyPortalWebApp1** is an ASP.NET WebForms application that serves as a **Policy Management Portal**.  
This project demonstrates building and deploying a web application with ASP.NET, Visual Studio, and SQL Server.  
It is uploaded here as part of my professional **portfolio showcase**.

---

## 🚀 Features
- User authentication and role-based access
- Manage policies (create, view, edit, delete)
- Secure database integration
- WebForms-based UI with ASP.NET controls
- Deployable to IIS / Azure App Service

---

## 🛠️ Tech Stack
- **Frontend / UI**: ASP.NET WebForms  
- **Backend**: C# (.NET Framework)  
- **Database**: SQL Server  
- **IDE**: Visual Studio 2019 / 2022  
- **Deployment**: IIS / Azure App Service

## ⚙️ Setup Instructions
1. Clone this repository:
   ```bash
   git clone https://github.com/<your-username>/PolicyPortalWebApp1.git

2. Open `PolicyPortalWebApp1.sln` in Visual Studio.

3. Restore NuGet packages (Tools → NuGet Package Manager → Restore).

4. Configure your connection string in Web.config.
   Example: Web.config.example provided.

5. Press F5 (IIS Express) or publish to IIS/Azure App Service.
